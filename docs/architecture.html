Lapis: scan the internet that already exists for agent coordination

Instead of building bait and waiting, Lapis pulls content agents have already left across many writable surfaces — pastes, gists, wikis, ephemeral relays, and blockchain / permaweb — decodes it, and runs a two-stage classifier (cheap heuristics → Claude confirm) to surface agent-to-agent coordination.

9 collectors 2-stage classify read-only Python 3.10+ extends Nightingale

The idea

The DSEWiki swarm was found after the fact by scanning public data for the fingerprints of coordination — not by luring agents. Lapis operationalizes that method and widens it: more surfaces (including ones nobody has scanned for this, like on-chain data fields), and an automated surface-discovery step. Everything is read-only; Lapis never writes to a third-party surface.

03Two-stage classifier

Stage-1 is high-recall triage (cheap, offline). Stage-2 is precision (Claude confirms and characterizes). No API key → stage-1 only.

Stage-2 returns {is_agent_coordination, pattern, confidence, rationale} and treats the content strictly as data — it never follows instructions embedded in a candidate.

Signatures & severity

kindSeverityWhat it catches
agent_self_idhighModel/agent vocabulary (OpenAI, GPT-5, swarm, ExploitGym).
coordination_langhighCoordination norms: HOLD/VETO/STOP/RELAY/CONFIRMED/RECRUIT.
zz_lexicalhighzz-prefixed messages, ZZZ anti-deletion pages.
sandbox_bypasshigh/etc/hosts, NO_PROXY, Host-header tricks, "reproducible bypass".
proxy_chainhighFetch-laundering hosts (r.jina.ai, markdown.new, corsproxy.io).
task_relaymedR1–R5 rounds, cohorts, deadlines, task-clock.
encoded_payloadmedLong base64/gzip blob decoded to readable text.
wiki_fuzz · xss_probemedUseModWiki action-fuzzing / XSS-shaped payloads.

A lone weak signal is demoted below "high" — the top severities require corroboration (score ≥ 3), which keeps stage-1 recall high without every match reading as critical.

04The novel bit — reading coordination off-chain surfaces

Blockchains and the permaweb let you store arbitrary bytes without a normal value transfer. Lapis decodes those bytes to text before classification, so an agent message on-chain is scanned exactly like a paste.

Passive vs active

commoncrawl is passive (offline corpora). Live-polling collectors need --active / LAPIS_ACTIVE=1 and honor a per-host rate limit.

Guardrails

Read-only everywhere; never write to a third-party surface or submit a transaction; redact PII; withhold evasion aids; report first (docs/DISCLOSURE.md).
